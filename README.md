# Simple Jumping Game 🎮

A responsive web-based jumping game built with HTML, CSS, and JavaScript.

## 🎯 Overview

The game challenges players to avoid obstacles by jumping. The score increases each time an obstacle is successfully passed.

## 🎮 How to Play

### Controls
- **Space / ↑ Arrow:** Jump
- **← Arrow:** Move left
- **→ Arrow:** Move right
- **Any key:** Start the game
- **Space:** Restart after Game Over

### Objective
Avoid obstacles for as long as possible and achieve the highest score.
